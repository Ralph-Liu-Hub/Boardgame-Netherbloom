# 《彼岸花渡》規則文件寫作風格（正體中文）

本文整理自作者親自修訂的 V5 規則書第 1–6 節。之後所有正體中文的規則文件（規則書、玩家輔助卡、卡牌與配件文字、網頁版提示）都依此撰寫。

## 1. 稱呼

- **亡魂稱「祂」**：規則文字與遊戲中的亡魂一律稱「祂」。故事文字（亡魂牌的故事段落、憶念之書序章）描述亡魂**還在世**的情境時，用「他／她」；描述亡魂**已經離世、或在冥府回憶**時，才用「祂」。指別人時也用「他／她」，例如新娘的丈夫是「他」；孩子的關鍵記憶「她離去前總是抱著我的那個人」裡的「她」是抱著孩子的人。
- 指名無名亡魂時寫 **亡魂「無名渡河」**，例如「亡魂為「無名渡河」時改用 8 張迴響牌」，避免和一般的「無名」混淆。
- 說明規則時對玩家用「你／你們」；要點出是哪一位玩家時寫清楚身分：**本回合玩家**、**持有○○稱號的玩家**、**擁有收割者稱號者**、**指定的另一位玩家**。

## 2. 用詞要完整

- 配件寫全名：**迴響標記**（不是「迴響」移動）、**結標記**、**傷疤標記**、**遺忘標記**、**記憶牌**、**守魂者稱號**、**命運織機**、**故事書路線**。
- 牌庫寫清楚是哪一疊：第一次出現寫「記憶牌牌庫頂的 1 張記憶牌」，之後可用簡稱「牌庫」（用語表已定義）。
- 動作寫出對象與方向：「將遺忘標記在遺忘軌上退 1 格」「把 1 個根指示物翻面成花」「將命運織機上與卡牌絲線相同的結軌上打 1 個結」。
- 落敗條件用語：**消散、破碎、滅頂、失落**。

## 3. 句型

- 條件句用 **「若……，則……」「當……時」「且」「並」**，把每個條件都寫出來，不靠讀者推論。
  - 例：「檢查打出這張牌之前迴響標記在哪條絲線上。如果與這張牌的絲線相同：且這是第一個行動時，執行卡牌的共鳴效果；且這是第二個行動時，不能執行卡牌的共鳴效果。」
- 正反兩面都寫：不只寫「可以」，也寫「不能」的情況（例如第二個行動不能共鳴）。
- 用 **「立即」** 取代「現在」；用 **「而非」** 取代「而不是」；用 **「即是」「稱為」** 下定義。
- 避免口語省略：「每回合最多使用一次」而非「每回合最多一次」；「不論放置根、或獲得光」而非「不論哪一種」。
- 時機欄位標題用 **「使用時機」**。
- 補充規則的引言用「以下為補充規則：」。

## 4. 結構與編排

- 章節用 `## N. 標題`。需要被引用的步驟小節加編號 **`### N-M. 標題`**（例如 4-1 正面打出、5-1 亡魂行動），引用時寫 **「（見第 4-1 節）」**。
- 遊戲中會反覆查閱的程序（第 4-1 到 4-5 節、第 5-1 到 5-3 節）放在方框裡：`<div class="rulebox" markdown="1">` …… `</div>`。例子放在方框外。
- 步驟清單裡，每一步開頭用粗體的短標題，例如「**判定能否前進**：」「**離開一格時**：」「**判定額外移動**：」。
- 首次提到另一節的規則時，在句尾加「（見第 N 節）」。
- 新手建議用一般段落「**新手的第一局**：……」，不用引用框。
- 用語表的第一欄是用語；有專屬指示物或標記的用語，在文字後面放上它的圖示（`docs/rules/icons/`）。附錄 A 的配件欄也一樣。

## 5. 數字與排版

- 中文與阿拉伯數字之間留半形空格：「1 張」「第 4-1 節」「7 結」。
- 數量範圍用「–」：「6–8 張」「第 1–13 格」。
- 絲線、欄位等並列用頓號「、」；章節內的配對用「・」，如「釋懷・人物」。
- 規則書不寫模擬勝率或其他測試數據。
