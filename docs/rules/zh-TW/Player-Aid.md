# 《彼岸花渡》Netherbloom — 玩家輔助卡

依照需要的順序，列出遊戲所需的一切。規則書以完整篇幅說明相同的規則。

### 勝利與落敗

亡魂抵達彼岸（第12格）時，**你們勝利**。所有人一起勝利或一起落敗。

**發生以下任一情況，你們立即落敗：**

- **消散**：遺忘堆達到燈籠的上限（8–11張；渡帳上的✕）。
- **破碎**：亡魂承受第3道裂痕。
- **滅頂**：必須放置黑水，但渡帳的黑水供應區已空。

### 交談：隱憶之約

可以盡情討論計畫與桌面，也可以說出自己握有哪些絲線（例如「2張執念、1張忘卻」）。絕不展示手牌，也絕不說出任何1張牌的名稱、效果、**共鳴**或記憶。

### 遊戲準備

1.  **河流**：依序拼好3塊圖板（第一河段在左，第三河段在右）。將各河段的河岸板塊分開洗混，霧面朝上放置到該河段的方槽中（第2–4、5–8、9–11格）。第1格兩岸各放置1個花指示物；將亡魂標記放置在第0格。
2.  **亡魂與燈籠**：選擇兩者。亡魂牌的特色規則整局有效。起始的光：「*最後火光的孩子*」3點，「*留在冥府的新娘*」1點，其他0點。
3.  **燈籠**：溫和：黑水6個、**遺忘**11張消散、每河段凶霧0張；標準：黑水5個、**遺忘**10張消散、每河段凶霧2張；困難：黑水4個、**遺忘**9張消散、每河段凶霧3張；英雄：黑水3個、**遺忘**8張消散、每河段凶霧3張。
4.  **記憶牌庫**：32張基本記憶牌加上亡魂的8張專屬牌（*無名渡河*用8張迴響牌），洗混後面朝下。旁邊留出面朝上的棄牌堆位置。
5.  **迷霧牌庫**：每個河段一副：該河段的10張基本迷霧牌、「漲水」與「怨念逼近」，再隨機加入燈籠規定張數的凶霧牌。分別洗混後，面朝下橫放到各河段的迷霧牌槽中。
6.  **命運織機**：結放置在旁邊；迴響標記放置在旁邊（第一張**正面打出**或**焚燒**的牌打出時放上絲線）。
7.  **渡帳**：燈籠規定數量的黑水放進黑水供應區（其餘放回盒中）；裂痕放置在旁邊。被**遺忘**的牌放置在它的編號軌上。
8.  **稱號**面朝上；亡魂的**憶念之書**翻到第一頁，信物牌依河段面朝下疊成三疊，結局牌面朝下放在書旁；其餘標記放成供應區。
9.  **玩家**：每人發3（單人4）張手牌；每人拿1個破浪標記（面朝上）；起始玩家拿船槳。單人：將幽靈牌洗混成一副牌庫。

### 你的回合

1.  **召喚稱號**（可選，在**回應**之前）：支付3點光（「*渡船上的國王*」時2點），並棄掉1張與該稱號同絲線的牌；拿取該稱號。每位玩家整局只能持有1個稱號（單人：可換成另一個，舊的永久放下；最多**召喚**3次）。
2.  **回應**（第一個行動），擇一：
    - 打出1張牌：**正面打出**、**背面打出**或**焚燒**（見下）；
    - **喚回**：支付3點光，將遺忘堆中任一張牌移到棄牌堆；
    - **奮力駛過**（見下）。

    只有**回應**能**共鳴**：作為**回應**、**正面打出**或**焚燒**、且與迴響同一絲線的牌，另外執行它的**共鳴**效果（「改為」則取代一般效果）。
3.  **掌舵**（第二個行動）：打出1張牌或**奮力駛過**。**掌舵**永遠不會**共鳴**。
4.  **回合結束**：執行回合結束步驟（見下）。

### 打出牌的方式

- **正面打出**：執行效果（若**共鳴**，另外執行**共鳴**效果）。在其絲線打1個結，並將迴響移到該絲線。然後：執念牌或釋懷牌面朝上放入棄牌堆，或者若它**共鳴**、且目前河段那一頁的對應欄位是空的，可以**銘刻**進憶念之書（關鍵記憶只要**正面打出**就能**銘刻**）；忘卻牌則被**遺忘**。
- **背面打出**：放置1個根，忽略牌上的文字。不打結，迴響不移動。這張牌面朝上放入棄牌堆。
- **焚燒**（每回合最多一次）：另一位握有同一絲線牌的玩家與你一起。你們各將1張該絲線的牌面朝下放出，再一起翻開；由你選1張，執行它的效果**兩次**。在該絲線打1個結並將迴響移到那裡。兩張牌都被**遺忘**；另一位玩家抽1張牌。沒有其他人握有該絲線 → 不能**焚燒**。**單人**：**焚燒**1張牌：效果兩次、打1個結、移動迴響，然後**遺忘**它與牌庫頂的1張牌。
- **奮力駛過**（每位玩家整局一次）：只能在下一格兩岸都有怨念、且該格沒有黑水時使用。移除兩個怨念，將亡魂移到該格（獲得其光），將你的破浪標記翻面。亡魂承受1道裂痕，之前每有1個已翻面的破浪標記再加1道，並**遺忘**牌庫頂的1張牌。

### 根與花

- **放置根**：將根指示物放置在亡魂所在格或前方的空河岸（沒有任何指示物）。它必須相連：位於亡魂所在格或下一格，或同格另一岸已有根或花指示物，或同一側河岸的前1格或後1格有根或花指示物。
- **霧**：在霧面河岸**放置根**時，翻開河岸板塊。**沃土**：根留下。**石地**：只有「即使在石地上也可以」或織根者才行，否則將這個根指示物放回供應區。**記憶之地**：根留下；從該河段那一疊抽1張信物牌，朗讀後放在憶念之書該頁旁（以「*無名渡河*」進行遊戲時改為獲得2點光）。**墳墓**：不放根；改放1個怨念指示物。
- **綻放**：將亡魂所在格或前方的1個根指示物翻到花面。有花指示物的格子即被**照亮**；亡魂只會移動到被照亮的格子（漂離時例外）。**凋零**：將花指示物翻回根面。

### 回合結束（每位玩家的回合之後，依序）

1.  **引花人**：若你持有引花人稱號，可以免費使1個根**綻放**。
2.  **亡魂行動**（依序檢查，執行第一個符合的情境）：
    1.  若亡魂旁有認命標記：亡魂不移動；**遺忘**牌庫頂的1張牌；移除標記。跳到*d*。
    2.  否則，若下一格被照亮且沒有黑水：亡魂移到該格。離開的那一格上每有1朵花獲得1點光，然後清空那一格（根、花與怨念指示物放回供應區）。進入新河段時，清除織機上所有的結。接著檢查一次**額外移動**：**遺忘**6張以上但未達9張（***輕如灰燼***）時，只有在下一格被照亮且沒有黑水時再走一格；**遺忘**9張或以上（***漂離***）時，即使下一格黑暗或淹水也一定再走一格，若是如此則承受1道裂痕（守魂者可以阻止）。
    3.  否則亡魂無法移動：它**徘徊**。依序：堅守標記在場、守魂者尚未使用，或亡魂所在格被照亮 → 不**遺忘**；「*留在冥府的新娘*」可改為移回前一格（整局一次）；以上皆非 → **遺忘**牌庫頂的1張牌。
    4.  最後一定執行：亡魂所在格任一岸有怨念指示物時，承受1道裂痕。
3.  **迷霧**：翻開目前河段迷霧牌庫頂的1張牌並執行，再放到牌槽旁的迷霧棄牌堆。牌庫已空：將該河段的基本迷霧牌洗混成新牌庫。
4.  **整理**：兩岸都有根或花指示物的格子上的黑水放回盒中。同一側河岸前1格與後1格都有花指示物的怨念指示物放回供應區。
5.  **抽牌**補到3（單人4）張（牌庫已空：將棄牌堆洗混成新牌庫）。
6.  **單人**：翻開1張幽靈牌並執行；打它的結並移動迴響；再整理一次。
7.  **傳遞船槳**給左手邊的玩家。下一回合：移除堅守標記；守魂者在持有者的回合開始時轉正；未使用的護盾在其擁有者的下一個回合結束時移除。

### 命運織機（絲線打滿4（2–3人）或5（單人、4人）個結）

絲線打滿時立即引發反噬，然後取下該絲線上所有的結：

- **執念・攫取**：在亡魂所在格放1個怨念指示物（左岸優先，再右岸；兩岸都有時放下一格；該河岸的根或花指示物放回供應區）。
- **釋懷・認命**：將認命標記放置在亡魂旁（下一次亡魂行動它停留並**遺忘**1張）。
- **忘卻・漲潮**：在下一格放置黑水。

### 威脅

- **黑水**：從渡帳的供應區拿取，只放在亡魂前方的格子。該格已有黑水時，放置在前方下一個沒有黑水的格子。該格的花指示物**凋零**。亡魂不能進入。被移除的黑水放回盒中。
- **怨念指示物**：放置在指定的河岸；已被佔據就放另一岸；兩岸都有就放下一格。那裡的根或花指示物放回供應區。有怨念指示物的河岸不能放根。
- **裂痕**：每道放置在渡帳的下一個圓圈；第3道即破碎。護盾標記抵銷下一道。
- **遺忘**：被**遺忘**的牌面朝上放置在渡帳的編號軌上。6張：輕如灰燼・9張：漂離・8–11張：消散（落敗）。

### 光與稱號

光屬於所有玩家共用的資源。亡魂離開的每一格上每有1個花指示物，獲得1點光。花3點光可以**喚回**（作為**回應**）或**召喚**稱號。

- **織根者**（執念）：你的根可以生長在石地上。你每回合的第一個根效果額外放置1個根。
- **守魂者**（執念）：每輪一次，阻止亡魂**徘徊**或漂離。
- **引花人**（釋懷）：你的每個回合結束時，免費使1個根**綻放**。
- **破霧者**（忘卻）：你每回合打出的第一張忘卻牌改為棄掉，而非**遺忘**。

### 憶念之書

- 每一頁的每一組相鄰欄位，在第二個欄位被**銘刻**時給予一次獎勵：
- 第一頁：地點＋人物：放置1個根。・人物＋事蹟：使1個根**綻放**。・事蹟＋感受：獲得2點光。
- 第二頁：地點＋人物：**驅散**最近的怨念。・人物＋事蹟：**排乾**最近的黑水。・事蹟＋感受：在最滿的絲線上解開1個結（若平手，由你選擇）。
- 第三頁：地點＋人物：將最新被**遺忘**的那張牌放回棄牌堆。・人物＋事蹟：**修補**1道裂痕。・事蹟＋感受：若下一格已被照亮，亡魂立即前進一格。
- 整頁填滿（4張；*花環少女*3張）時另外給予**章節祝福**：移除1道裂痕；若沒有，移除前方最近的黑水；若沒有，將最新被**遺忘**的牌放回棄牌堆。

### 卡牌用語

- **驅散**怨念／**沖走**怨念：放回供應區。**排乾**黑水：移除並放回盒中。
- **修補**：移除1道裂痕。**解開**／**清空**最滿的絲線：移除結，不引發反噬（平手由你選擇）。**打結**：加結（打滿 → 反噬）。
- **遺忘**：將牌面朝上放置在渡帳的編號軌上。**徘徊**：亡魂不移動。**掀開霧氣**：翻開1個河段的河岸板塊但不放根；墳墓變為沃土。

### 結局

遊戲結束時，隱憶之約解除。逐頁朗讀憶念之書：空欄位讀作「……但這一段，已被河水帶走」，每頁讀完後接著朗讀該頁旁的信物。若你們獲勝，查看關鍵記憶在哪裡（已**銘刻**、已**遺忘**或未曾說出）與**遺忘**張數，最後朗讀符合的結局牌；若隱藏結局的條件全部符合，就以它取代條件中寫明的結局。
