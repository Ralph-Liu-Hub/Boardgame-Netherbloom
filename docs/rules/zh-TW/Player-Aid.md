# 《彼岸花渡》Netherbloom — 玩家輔助卡

> **立即落敗：消散**：遺忘堆達到燈籠的✕（8–11）・**破碎**：第3個裂痕圓圈被填上・**滅頂**：必須放置黑水但供應區已空。亡魂抵達彼岸時**勝利**。

### 你的回合

1.  **召喚**: 可選・支付光，棄掉1張同絲線的牌。單人：可換成新的稱號（舊的永久放下），一局3次
2.  **回應**: 你的第一個行動：正面打出或焚燒、且與迴響同一絲線的牌會共鳴
3.  **掌舵**: 你的第二個行動。任一行動都可改為奮力駛過（每位擺渡人整局一次）；每回合最多焚燒一次
4.  **回合結束**: 1 引花人・2 亡魂步驟：下一格已照亮且沒有黑水就移動，否則徘徊・3 迷霧：翻開本河段牌庫頂的1張牌・4 整理・5 補滿手牌・6 單人：幽靈・7 傳遞船槳
5.  **整理**: 兩岸都有圓片的格子移除黑水；同側前後兩格都有花的怨念放回供應區

### 打出卡牌

- **正面打出**: 效果＋結＋新迴響
- **背面打出**: 放置1個根；不加結，迴響不動
- **焚燒**: 每回合一次，與握有同一絲線的玩家各翻開一張，由你選一張；效果×2＋結＋新迴響；遺忘兩張，對方抽1張。單人：一張牌，遺忘它與牌庫頂的1張
- **喚回**: 僅限回應；花3點光，選一張被遺忘的牌回到棄牌堆
- **奮力駛過**: 下一格兩岸都有怨念（且沒有黑水）：移除兩個怨念並把亡魂移到該格；1道裂痕（每個背面朝上的破浪標記+1），遺忘1張；每位玩家整局一次

### 絲線（4–5個結）

- **執念**: 打滿：在亡魂所在格放置怨念
- **釋懷**: 打滿：亡魂在下一次亡魂步驟中不移動
- **忘卻**: 打滿：在下一格放置黑水。打出的牌放入遺忘堆

### 根必須連接根網

亡魂所在格或下一格、同一格的對岸，或相鄰格的同側河岸。

- **9**: 漂離：多移動1格；進入未照亮的格子時承受1道裂痕
- **8–11**: 消散：遊戲失敗
