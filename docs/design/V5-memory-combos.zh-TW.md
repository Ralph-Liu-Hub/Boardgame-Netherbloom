**寫法標準**（11/7）：
- 句子不替空格決定情緒、性別或關係；空格放在「想起、記得、心裡只有、曾經」這類中性位置。

- 情緒交給句子的其他部分，或交給那條路線（執念、釋懷、忘卻）。
