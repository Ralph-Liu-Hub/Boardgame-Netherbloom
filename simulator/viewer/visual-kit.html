Netherbloom Visual Kit

The palette, type, icons, cards and boards for the Western base box. The simulator's game viewer draws from exactly this kit, so what you see in a simulated game is what a prototype on the table will look like. Final art replaces the placeholder artwork; the colours, icons and layouts stay.

Card size 63 × 88 mm · Icons 48-unit grid · Minimum print size 8 mm

01 · Palette

Ink, bone and one living red

About 70% of every surface is ink and ash. Crimson is reserved for the Netherbloom and the Obsession thread; spectral cyan for everything from beyond (Oblivion, Grievances, the Ghost). Colour is never the only signal: every thread and threat also has its own shape.

02 · Type

Engraved titles, plain rules

Titles borrow from 19th-century engraving and memorial printing. Rules text is a humanist sans for reading at 7 pt across a table. Story bands are set in italic serif, so the Book reads like handwriting in an album.

03 · Icons

Original icon set

Every icon is drawn for Netherbloom, with no stock glyphs or emoji. Each passes the silhouette test at 8 mm. The second row of the threads shows them in greyscale, as a colour-blind player would rely on them. The ID under each icon is the name the simulator viewer uses.

Karma knot · three options

The knot tied on a Loom thread each time a card is played. The physical piece is a wooden bead, so the icon is drawn as something threaded on a cord.

A · The Fates' Knot Recommended for the base box Three interlaced loops, one for each thread of the Loom, bound by a ring. Echoes old Northern European knotwork. It ties the icon to the game's three threads. nb-knot
B · The Turning Bead For The Other Shore Tai chi style: two threads turning around each other, light inside dark. Strongly Eastern, so it fits the expansion's Three-Lives Stone rather than the base box. nb-knot-taichi
C · The Totem Bead A carved wooden bead with a spiral of fate cut into it. Culture-neutral, so one piece could serve both boxes, and it matches the real wooden component. nb-knot-totem

04 · Cards

Card templates

Every Memory card has the same four zones: thread and name at the top, effect and Resonance, artwork, and the story band at the bottom. Cards overlap in the Book so that only the bone-coloured story band shows. Oblivion cards carry a fading fragment instead of a band, because they are always forgotten.
