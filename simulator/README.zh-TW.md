# 《彼岸花渡》Netherbloom 模擬器

由跟隨迴響的 AI 玩家進行數千場 Netherbloom 對局，並回報遊戲的平衡程度與節奏表現。它依據 **GDD v0.4**（遊戲設計文件）中的規則，以及 **Card Compendium v0.2**（卡牌與配件總覽）與 **Soul Roster v3**（亡魂名冊）中的卡牌建立模型。

## 快速開始

只需 Python 3.10 以上版本，沒有任何相依套件。

```bash
cd simulator
python3 -m netherbloom.report --games 1000 --out reports      # full balance suite (about 75 s on 4 cores)
python3 viewer/build_viewer.py --players 3 --seed 13            # replay one game as an HTML page
python3 -m unittest discover -s tests                           # tests
```

試跑單一設定：

```python
from netherbloom.stats import run_batch, fmt
print(fmt(run_batch(500, players=4, lantern=2, soul="open", hand=4)))
```

遊戲中的每個數值都是一個 `Config` 選項（`netherbloom/engine.py`），因此只要一個參數就能測試規則變更。

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `netherbloom/cards.py` | 所有卡牌、迷霧、板塊、燈籠與幽靈的資料 |
| `netherbloom/engine.py` | 規則：狀態、卡牌效果、亡魂步驟、迷霧、威脅、命運織機、憶念之書、稱號、單人模式的幽靈 |
| `netherbloom/agent.py` | 跟隨迴響的 AI 玩家 |
| `netherbloom/game.py` | 執行一場對局；可錄製重播 |
| `netherbloom/stats.py` | 批次執行與摘要統計 |
| `netherbloom/report.py` | 完整的平衡測試套件，輸出至 `reports/` |
| `viewer/` | 重播頁面產生器。使用 `viewer/visual-kit.html` 中的圖示集（與美術方向使用同一套）。 |
| `tests/` | 單元測試 |

## AI 玩家

如同實際遊戲，玩家之間不能交談：
- 每位玩家只看得到自己的手牌與公開的版圖。
- 每個回合，它會以每張牌所有可行的打法逐一嘗試（正面打出、背面打出、焚燒），以及尋覓；光足夠時會考慮喚回，路被封住時也會考慮奮力駛過。單人模式中它可以更換稱號，但只在沒有可喚回的牌時才這麼做。
- 它會將結果推演到亡魂步驟，並保留最佳的一組兩張牌打法（以第一張牌進行集束搜尋）。
- 它傾向回應迴響，並留下下一位玩家能安全跟隨的迴響。
- 規劃時，它無法看見霧下的內容。

## 對 GDD v0.4 提出的調整建議

依原文撰寫的 GDD v0.4 **並不平衡**：
- 不同玩家人數下的勝率介於 40% 到 78% 之間。
- 所有落敗中有 82–91% 是因為消散，而滅頂從未發生。
- 每場遊戲只持續 10–12 個回合。

以下調整讓無名渡河在標準燈籠下、每種玩家人數的勝率都落在 **56–62%**（孩子以外四個亡魂的平均為 52%），且三種失敗條件平均分攤了落敗：

| 規則 | GDD v0.4 | 調整後 |
|---|---|---|
| 徘徊 | 一律遺忘 1 張 | 僅在亡魂所在的格**未被照亮**時才遺忘 1 張（在自己的光旁等待的亡魂不會遺忘） |
| 被排乾的黑水 | 放回供應區 | **移出遊戲。**供應區的黑水（標準燈籠為 6 個）成為緩慢推進的洪水計時器，讓滅頂成為真正的威脅。 |
| 焚燒 | 遺忘該牌 | 遺忘該牌**並再遺忘 1 張** |
| 輕如灰燼／漂離 | 遺忘 4／8 張 | **6／9** |
| 迷霧牌庫 | 每個河段 10 張 | **12 張**：+1 張漲水、+1 張怨念逼近 |
| 手牌上限 | 5／5／4／3（單人／2／3／4 人） | **4／3／3／3** |
| 每條絲線的結數 | 5 | **2–3 人時為 4，單人與 4 人時為 5** |
| 章節祝福 | 頁面填滿（4 個欄位） | **4 個欄位中填滿 3 個**（花環少女的特色規則：2 個） |
| 關鍵記憶 | 僅在共鳴時銘刻 | **只要正面打出**即可銘刻 |
| 單人模式的幽靈 | 它的忘卻牌會遺忘 1 張 | **不會遺忘** |
| 新娘的特色規則 | 每個河段被拉回一次，仍會遺忘 | **每場遊戲**被拉回一次，不遺忘任何牌 |
| 新娘專屬牌組 | B02 護盾、B06 修補 | **B02 頑根、B06 盛放** |
| 行動 | 打出 2 張牌 | **2 個行動**：打出一張牌、尋覓（棄掉 1 張、抽 1 張；每回合一次），或奮力駛過（見下）；只有第一個行動（**回應**）能共鳴；第二個行動稱為**掌舵** |
| 前方兩岸皆有怨念 | 亡魂徘徊 | 亡魂仍會徘徊，但玩家可以花 1 個行動**奮力駛過**（每位玩家整局一次）：兩個怨念散去，亡魂前進一格，承受 1 道裂痕並遺忘 1 張；同一場遊戲中每再駛過一次，多 1 道裂痕 |
| 光 | 只能召喚稱號；稱號被取走後便不斷累積 | 新增**喚回**：以回應花費 3 點光，選一張被遺忘的牌放回棄牌堆。**單人模式**：持有稱號時仍可召喚新的稱號，原稱號永久放下，每個稱號只能召喚一次，一局最多 3 次。閒置的光從 37% 的回合降到 2%（`experiments/light_sinks.py`） |
| 燈籠 | 1–5 | **溫和 6/14/0、標準 6/11/2、困難 4/10/3、英雄 3/9/3**（黑水／消散門檻／每河段凶霧數） |
| 孩子的特色規則 | 3 點光、每河段第一道裂痕忽略、永不漂離、沒有凶霧 | 另外**消散前可多遺忘 1 張牌** |

## 尚未建立模型

- 無名亡魂（生平、創傷與遺願）。
- 隱藏結局。
- 東方擴充。
- 玩家失誤。AI 從不會忘記規則，因此實際的第一場遊戲會比這些數字顯示的更困難。
