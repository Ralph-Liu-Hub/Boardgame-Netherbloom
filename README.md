# Boardgame-Netherbloom
This is a repository for the design and simulation of the tabletop board game Netherbloom (Traditional Chinese title: 《彼岸花渡》).

## Art
The painted illustrations (box, card backs, Soul portraits, river board, Books of Remembrance) are in [`art/`](art/README.md) as full-resolution lossless PNG masters.

The print-ready factory files for a prototype (every card, the river board, tokens, box, rulebook and the five Books of Remembrance, in English and Traditional Chinese) are built by [`print/factory/`](print/factory/README.md); the built PDFs are in `print/factory/dist/`.
