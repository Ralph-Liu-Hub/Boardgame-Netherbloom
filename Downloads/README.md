# Downloads (Rules V3.0, reworked art)

Click a file, then **Download** (or "View raw"). Each zip opens on its own.

| File | What is in it |
|---|---|
| `netherbloom-v3.0-for-drive.zip` | Illustrated Rulebook V3.0 (PDF + Word) and Player Aid, English and 正體中文, in folders named like the Google Drive folders; Markdown rulebooks; zh-TW Print & Play; visual kit |
| `netherbloom-factory-en-V3.0-part1-cards-boards-books.zip` | English factory files: MANUAL, cards, tokens, Ledger, Loom, river board, Books of Remembrance |
| `netherbloom-factory-en-V3.0-part2-box-rulebook.zip` | English factory files: box and rulebook |
| `netherbloom-factory-zh-TW-V3.0-part1-cards-boards-books.zip` | 正體中文 factory files: MANUAL, cards, tokens, Ledger, Loom, river board, Books |
| `netherbloom-factory-zh-TW-V3.0-part2-box-rulebook.zip` | 正體中文 factory files: box and rulebook |
| `netherbloom-screentop-en-V3.0.zip` | Screentop.gg asset pack and setup guide |

The factory files are split in two per language because GitHub refuses files over 100 MB.
`SHA256SUMS.txt` lets you check a download is complete (`shasum -a 256 <file>` on a Mac).
